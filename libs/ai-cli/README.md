# `@aq-architect/ai-cli`

Developer CLI for the Enterprise AI Workspace.

## Install

```bash
npm install -g @aq-architect/ai-cli
```

## Usage

```bash
ai-cli ping
ai-cli gateway-url
ai-cli --help
```

## Library usage

```ts
import { createAiCli, runAiCli } from '@aq-architect/ai-cli';

runAiCli();
```
